# 判别器训练数据切分报告（CGEC-Faith）

> 自动生成：`scripts/prepare_train_data.py`，重跑即更新。

## 方法与参数

- 源数据：`results/full/标注表_全量_定稿.csv`（6000 条 = 2000 句 × 3 模型，GBK）。
- 实例 = 一条 `(原句 src, 大模型改句 hyp)` 对；标签取「你的标注」列（定稿）。
- 切分单位 = 句子（2000 句），同一句的 3 条模型输出不跨 train/val/test，避免原句泄漏。
- 分层键 = 该句 3 条实例里「最严重」标签（优先级 幻觉 > 语义漂移 > 过度纠正 > 漏改 > 忠实正确）。
- `StratifiedShuffleSplit`，`random_state=42`，句子级比例 train:val:test = 80:10:10。
