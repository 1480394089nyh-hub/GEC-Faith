# CGEC-Faith: A Chinese LLM Correction Failure-Mode Dataset + Faithfulness Discriminator

> **CGEC-Faith** is the first dataset annotating the **failure modes** of large-language-model Chinese grammatical error correction (GEC), together with a trained "correction faithfulness discriminator". It demonstrates that the failure modes F0.5-style metrics cannot capture are **annotatable, learnable, diagnosable, and usable as a quality gate**.

## Overview

- **Dataset**: 2000 Chinese error sentences (NLPCC-2018 test set) x 3 LLMs (deepseek / qwen / glm), each correcting once = **6000** `(source -> correction)` pairs, human-annotated with 5 failure-mode labels.
- **Discriminator**: trained on `hfl/chinese-roberta-wwm-ext`, for binary (faithful / unfaithful) and 5-class (failure-type) classification.

## 5 Failure Modes

| Label | Meaning |
|---|---|
| 忠实正确 (faithful-correct) | correction is correct, fluent, meaning preserved |
| 过度纠正 (over-correction) | changes correct parts into wrong / less fluent |
| 语义漂移 (semantic drift) | the edit changes the original meaning |
| 幻觉 (hallucination) | adds content absent from the original |
| 漏改 (missed) | errors left unfixed, sentence still has errors |

## Main Results

- **Annotation agreement**: double-annotated subset (300) κ = 0.7539 (substantial); full 6000-set main-annotation + AI review: 93.0% initial agreement, 98.53% after adjudication.
- **Discriminator** (600 held-out test examples):
  - binary: Accuracy 0.737±0.014; faithful F1 0.818±0.016 / unfaithful F1 0.522±0.018 (3 seeds mean±std; vs "always-faithful" baseline 0).
  - 5-class: Accuracy 0.691±0.022; faithful-correct 0.793±0.015 / missed 0.469±0.040 / semantic-drift 0.262±0.043 / over-correction 0.576±0.131 / hallucination 0.
- **Discrimination**: models with nearly identical F0.5 (deepseek 0.328 / glm 0.327, Δ=0.0008) differ in failure-mode distribution by **TVD = 0.21**.
- **Quality gate**: using the discriminator as a post-filter raises output faithfulness **68.67% -> 77.28% (+8.61pp)**, keeping 88.35% of good corrections.

## Dataset

- File: `results/full/标注表_全量_定稿.csv` (6000 rows, 5 columns: `序号 / 原句 / 模型 / 大模型改句 / 标签`).
- Double-annotated subset (300 rows, for kappa): `results/annotation/双标_300_我.csv`, `双标_300_同学.csv`.
- Encoding: **GBK** (Windows Simplified Chinese). Read with `pandas.read_csv(..., encoding="gbk")`, or open with GBK encoding in an editor.
- Source: original sentences from the **NLPCC-2018 GEC shared-task test set** (see citation below); corrections generated by deepseek / qwen / glm; labels are human-annotated.
- License: **CC BY 4.0** (see `DATA_LICENSE.md`).

> **NLPCC-2018 citation**: Yuanyuan Zhao, Nan Jiang, Weiwei Sun, Xiaojun Wan. *Overview of the NLPCC 2018 Shared Task: Grammatical Error Correction*. NLPCC 2018.
> Original data: http://tcci.ccf.org.cn/conference/2018/ (test `source.txt` + reference `gold.0.txt`).

## Reproducing (what needs the NLPCC data)

- **Training the discriminator + quality gate**: only the dataset CSVs in this repo are needed; no extra download.
- **Computing kappa**: `python scripts/compute_kappa.py results/annotation/双标_300_我.csv results/annotation/双标_300_同学.csv`.
- **Discrimination / data collection**: requires the NLPCC-2018 test set; download it from the link above and place it under `data/raw/nlpcc2018/extracted/Data/test/` (containing `source.txt` and `gold/gold.0.txt`).

## Installation

```bash
git clone https://github.com/1480394089nyh-hub/GEC-Faith.git
cd GEC-Faith
pip install -r requirements.txt   # only discriminator training needs torch/transformers/etc.; data & scoring use stdlib only
```

## Quick Start

### 1. Configure API (only needed to reproduce data collection)

```bash
cp config.example.py config.py   # fill in your deepseek/qwen/glm api_key
```

### 2. Split data (for discriminator training)

```bash
python scripts/prepare_train_data.py   # final CSV -> results/discriminator/{train,val,test}.jsonl + label_map.json
```

### 3. Train the discriminator (needs GPU, one T4 is enough)

```bash
python src/train_discriminator.py --task bin     # binary: faithful / unfaithful
python src/train_discriminator.py --task multi   # 5-class: failure types
```

### 4. Quality-gate evaluation

```bash
python scripts/eval_quality_gate.py   # faithfulness before/after filtering, from test_predictions.csv
```

Others: `compute_kappa.py` (inter-annotator kappa), `verify_discrimination.py` (discrimination), `run_experiment.py` (single correction + F0.5 scoring).
